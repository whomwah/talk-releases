# talk-releases

This repository exists solely to host releases and the appcast for [Talk](https://github.com/whomwah/talk) — A macOS menu bar app for push-to-dictate into any app.

- **GitHub Releases** — holds the `.dmg` and `.zip` release assets
- **`gh-pages` branch** — serves the `appcast.xml` used by Sparkle for auto-updates

Do not commit source code here.
